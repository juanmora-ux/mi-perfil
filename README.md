## Requisitos previos

1. Node.js 20+ instalado (node -v).
2. App Expo Go instalada en tu teléfono (Android/iOS).
3. Cuenta gratuita en expo.dev.

## ¿Cómo correr el proyecto?

1. Crea el proyecto: npx create-expo-app@latest mi-perfil --template blank.
2. Entra a la carpeta y ejecuta npx expo start.
3. Escanea el QR con Expo Go y confirma que la app abre en tu teléfono.
4. Edita App.js para construir la tarjeta de perfil usando View, Text e Image.
5. Verifica que Fast Refresh actualiza la pantalla al guardar.
